# 把照片放进这个文件夹

上传照片时，请**停留在这一层文件夹**（`assets/photos/photography/`），直接点
**Add file → Upload files**，把照片拖进去就行。

上传后大约 1 分钟，网站会自动显示出来，**不需要改任何代码**。

## 注意

- 支持 `.jpg` `.png` `.webp`；**HEIC 不能直接上传**，请先在手机上导出成 JPG
- 单张建议 1MB 以内、长边 2000 像素左右（手机打开更快）
- **不要**传到 `thumbs/` 子文件夹 —— 那里是自动生成的小图，传进去网站看不到
- 删掉这里的照片，网站上也会跟着消失
